# صَوْغ | SOGH — Public Website V2.0

الموقع التسويقي الرسمي لوكالة صَوْغ — صفحة عامة موجهة للعملاء فقط. ليس دليل
هوية ولا مختبرًا ولا عدة مبيعات؛ تلك تعيش في المستودع القانوني للعلامة.

## المرجع القانوني للعلامة

`مجلد العلامة المحلي (خارج هذا المستودع)`هو مصدر الحقيقة الوحيد للشعارات والرموز والألوان
والخطوط والرسائل وبيانات التواصل المؤكدة. لا تُعدَّل أصول العلامة هنا —
تُعدَّل هناك ثم تُسحب عبر المزامنة.

## الأوامر

```bash
npm install        # أول مرة فقط (Node 20+)
npm run dev        # التطوير على http://localhost:5181
npm run build      # فحص TypeScript + بناء الإنتاج في dist/
npm run preview    # معاينة بناء الإنتاج على 5181
npm run sync:brand # سحب الأصول وبيانات التواصل من المستودع القانوني
npm run qa:shots   # لقطات كاملة على 1440/1280/1024/768/390/360 + الكونسول والتمرير الأفقي
                   # غيّر المصفوفة عبر متغير البيئة QA_WIDTHS
                   # QA_MOTION=1 للالتقاط مع تفعيل الحركة
npm run qa:typography # بوابة الطباعة العربية عبر خمسة عروض
npm run qa:marquee # شريط العملاء: الحركة وتقليل الحركة عبر خمسة مقاسات
npm run qa:ink     # قياس الفراغ بين أسطر الحبر من البكسل المرسوم (تقرير، لا حكم)
npm run qa:sections # لقطات قبل/بعد لكل قسم: node scripts/section-shots.mjs <label>
npm run qa:release # بوابة الإصدار الكاملة — شغّلها على بناء الإنتاج:
                   #   npm run build && npm run preview
                   #   SITE_URL=http://127.0.0.1:5181 npm run qa:release
```

## حالة إصدار r2 المحلي

أغلق إصدار r2 حاجز Windows Chrome عند عرض نافذة `320px` ومحتوى فعلي
`305px`: أزيل الحد الأدنى العام الذي كان يفرض مستندًا بعرض `320px` بعد ظهور
شريط التمرير، وأصبحت الشبكات أحادية العمود تقبل الانكماش الطبيعي. مرّ بناء
الإنتاج ومصفوفة الفحص من `280px` إلى `1440px` بلا تمرير أفقي أو عناصر تتجاوز
الحواف. لم يُنفذ نشر ضمن هذا الإصدار؛ التفاصيل في `FINAL-QA.md`.

## الخطوط

**جميع الخطوط مستضافة محليًا** في `public/fonts/` — لا اتصال بـGoogle Fonts
ولا ملف أنماط خارجي على المسار الحرج:

- **Alexandria** (متغير 300–900، عربي + لاتيني) — خط العرض.
- **IBM Plex Sans Arabic** (400/500/600، عربي + لاتيني) — خط النص.
- **Space Grotesk** (500/600، لاتيني) — الأرقام والعناوين الفرعية اللاتينية.

يُحمَّل مسبقًا وجهان فقط — العربية العرضية والعربية النصية بوزن 400 — لأنهما
الوجهان اللذان ترسم بهما الشاشة الأولى فعلًا. الباقي يصل عند الحاجة عبر
`unicode-range` و`font-display: swap`.

عائلتان طباعيتان فقط. لا تُضاف عائلة ثالثة.

## بيانات التواصل

`brand/contact.json` هو الملف الوحيد لبيانات التواصل العامة، ويُزامَن من
المستودع القانوني. القواعد:

- القيم الفارغة اختيارية وتُخفى تلقائيًا من الواجهة (لا روابط فارغة ولا
  فواصل مكررة ولا أيقونات وهمية).
- الهاتف مؤكد كهاتف فقط — **لا يُنشأ رابط واتساب** قبل تأكيده.
- **الدومين غير مسجل** — لا يُعرض أي دومين أو canonical أو sitemap قبل
  تأكيد التسجيل.
- X ولينكدإن غير متوفرين — يبقيان فارغين ومخفيين.

## مزامنة العلامة

`npm run sync:brand` ينسخ من المستودع القانوني: ملفات SVG المعتمدة
(الشعار العربي، SOGH، القفل الثنائي بنسختيه، الوحدة، الإشارة)، وحزمة
favicon وصورة OG، و`brand/contact.json`. الموقع يحمل نسخه الخاصة بعد
المزامنة ويبقى قابلًا للنقل والنشر بذاته. عدّل قائمة الملفات في
`scripts/sync-brand.mjs` عند الحاجة.

## بنية الكود

```
src/
  App.tsx              تركيب الصفحة فقط
  data/                المحتوى — نص واحد لكل حقيقة، لا تكرار داخل المكونات
    site.ts            الدومين، القائمة، بيانات SEO
    services.ts        مجموعات الخدمات (ومنها خيارات حقل «الخدمة المطلوبة»)
    method.ts          مراحل المنهج الأربع
    clients.ts         شعارات العملاء + مقياس الحجم البصري + علم plate
    intelligence.ts    استخدامات الذكاء الاصطناعي
    work.ts            دراسات الحالة — فارغة عمدًا (انظر أدناه)
  components/          مكون لكل قسم + Reveal وglyphs وForgeField
  styles/              tokens ثم base ثم layout ثم header ثم hero ثم sections ثم forms ثم motion
  motion.tsx           رموز العلامة المعتمدة (لا تُعدَّل هنا)
```

## قواعد المحتوى المفروضة في الكود

- **دراسات الحالة:** `data/work.ts` فارغة، فلا يظهر قسم «أعمالنا» ولا رابطه في
  القائمة. أضف عنصرًا موثقًا ومعتمدًا من العميل فيظهر القسم والرابط تلقائيًا.
  لا تُحوَّل شعارات العملاء إلى دراسات حالة، ولا يُنشر رقم بلا مصدر.
- **شعارات العملاء:** `data/clients.ts` — عنصر بلا `src` لا يُعرض إطلاقًا. لا
  Placeholder ولا شعار مُعاد رسمه ولا بديل نصي. الشعارات غير قابلة للنقر ولا
  تحمل اسمًا مرئيًا؛ الاسم في `alt` لقارئ الشاشة فقط.
- **الفريق:** القسم محذوف بقرار المالك (2026-09-09) — لا أسماء ولا أدوار ولا
  كيانات `Person` في البيانات المنظمة. إن أُعيد، فبصور معتمدة ومكوّن مستقل.

## قيد النموذج (موثق)

لا يوجد خادم للنموذج. نموذج «ابدأ مشروعك» يتحقق من الحقول المطلوبة
(الاسم، الجوال، البريد الإلكتروني، الخدمة، النبذة — واسم الشركة اختياري)
ثم يجهّز رسالة `mailto:` عربية منسقة إلى `soghagency@gmail.com`، ويعرض
رابط مراجعة قبل الإرسال. لا تُرسل أي بيانات إلى خادم ولا تُحفظ. عند اعتماد
باك-إند: استبدل `composeMailto` في `src/components/Contact.tsx` بنقطة نهاية
مُراجعة من ناحية الخصوصية، وكرّر التحقق على الخادم.
